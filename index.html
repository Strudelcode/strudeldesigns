Hinweis: Bilder werden clientseitig komprimiert und lokal im Browser gespeichert – Videos werden aus Speicherplatzgründen aktuell nicht unterstützt.

Hier verbindest du das Admin-Panel mit deinem GitHub-Repo. „Auf GitHub veröffentlichen“ schreibt data.json direkt in dein Repo – GitHub Pages liefert die neue Version dann automatisch an alle Besucher aus. Der Zugangstoken wird nur in diesem Browser gespeichert (localStorage) und nirgendwo sonst. Nutze am besten einen fine-grained Personal Access Token, beschränkt auf genau dieses Repo mit Berechtigung „Contents: Read and write“.
